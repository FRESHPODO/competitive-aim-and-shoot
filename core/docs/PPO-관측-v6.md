# PPO 관측 v6: 경기 시간 정보 제외

현재 보상 설정과 입력은 [알파 기반 v7](<C:/Users/hphci/Desktop/competitive aim-and-shoot/core/docs/PPO-관측-v7.md>)이다. 아래 성공 보상·실패 비용 두 입력은 알파 하나로 통합되어 총 22항목이다.

경기 경과 시간과 공통 게임 상태 갱신 후 경과 시간을 삭제했다. 남은 경기 시간과 설정된 타임아웃도 PPO 입력에 추가하지 않는다. 입력은 25차원에서 23차원으로 줄었다.

| 구분 | 전체 항목 | 수 |
|---|---|---:|
| 공통 게임 조건·상태 | 현재 타겟 체력, 최대 체력 대비 비율, 크리티컬 존 반지름 비율, 타겟 반지름, 타겟 이동 속도, 외곽 피해, 중앙 피해, 크리티컬 즉사 여부, 발사 쿨다운 길이 | 9 |
| 개별 동적 상태 | 내 남은 쿨다운, 상대 남은 쿨다운 | 2 |
| 내 노이즈 | 운동·위치 인지·속도 인지·시계 노이즈 | 4 |
| 내 PPO 보상 | 내 처치 보상, 상대 처치 시 내 실패 비용 | 2 |
| 이번 제안 | Th, tc, 예정 격발까지 남은 시간 | 3 |
| 조준 모델 가정 기반 추정 | 예정 격발 시 조준 오차, 추정 피해, 크리티컬 존 적중 추정 여부 | 3 |

쿨다운 길이·남은 쿨다운·계획 시간·격발까지의 지연은 공격과 계획의 속성이므로 유지한다. 시뮬레이션 진행과 기록에 필요한 내부 시각도 유지하지만 경기 경과·관측 갱신 후 경과·남은 경기 시간은 정책 벡터에 전달하지 않는다.

나머지 공통 조건, 발사 요청 때만 판단하는 동작, 가정 기반 피해 추정, 쿨다운에 걸린 제안의 추적 후 재판단, 승인 후 계획 유지는 [v5 설명](<C:/Users/hphci/Desktop/competitive aim-and-shoot/core/docs/PPO-관측-v5.md>)과 같다.

검증: 동일한 남은 쿨다운·계획 상태를 유지하면서 절대 시각을 옮겨도 입력이 동일하다. 관측 갱신 시각이나 타임아웃·남은 시간 필드를 바꿔도 입력이 동일하다. 모델 관측 크기는 23이며 이전 스키마 모델은 명확한 호환 오류로 처리한다.
