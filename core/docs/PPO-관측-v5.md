# PPO 관측 v5: 공통 게임 조건과 개별 상태

현재 입력은 [v6의 23항목](<C:/Users/hphci/Desktop/competitive aim-and-shoot/core/docs/PPO-관측-v6.md>)이다. 아래 표의 경기 경과 시간과 상태 갱신 후 경과 시간 2항목은 삭제됐다.

외곽 피해·중앙 피해·크리티컬 즉사 여부·발사 쿨다운 길이는 양쪽에 동일하게 적용되는 공통 게임 조건이다. PPO에 한 번만 입력한다. 현재 남은 쿨다운은 두 플레이어의 실제 발사 이력에 따라 각각 계산한다.

| 구분 | 전체 항목 | 수 |
|---|---|---:|
| 공통 게임 조건·상태 | 현재 타겟 체력, 최대 체력 대비 비율, 크리티컬 존 반지름 비율, 타겟 반지름, 타겟 이동 속도, 외곽 피해, 중앙 피해, 크리티컬 즉사 여부, 발사 쿨다운 길이 | 9 |
| 개별 동적 상태 | 내 남은 쿨다운, 상대 남은 쿨다운 | 2 |
| 내 노이즈 | 운동·위치 인지·속도 인지·시계 노이즈 | 4 |
| 내 PPO 보상 | 내 처치 보상, 상대 처치 시 내 실패 비용 | 2 |
| 이번 제안 | Th, tc, 예정 격발까지 남은 시간 | 3 |
| 조준 모델 가정 기반 추정 | 예정 격발 시 조준 오차, 추정 피해, 크리티컬 존 적중 추정 여부 | 3 |
| 시간 | 경기 경과 시간, 공통 게임 상태 갱신 후 경과 시간 | 2 |

합계 25차원. 자기·상대에 중복 입력하던 공격 조건 4개를 합쳤다. 상대 노이즈·보상함수·조준 상태·계획 및 총기 종류·탄 퍼짐은 입력하지 않는다.

범위 조건은 경기마다 한 번만 추출하여 양쪽에 같은 값을 적용한다. 남은 쿨다운은 같은 길이를 쓰더라도 실제 발사 시각이 다르므로 서로 다를 수 있다.

기존 A/B 공격 조건을 사용하는 설정 파일은 양쪽의 유효한 값 또는 분포가 동일해야 한다. 서로 다른 값을 조용히 선택하지 않고 공통 조건 확인 오류를 낸다. 공통 키 `minDamage`, `maxDamage`, `instantKill`, `cooldown`으로 제공한 설정은 양쪽에 동일하게 적용한다. 기존 총기별 설정 화면의 완전한 제거는 이 관측 분류 수정과 별도다.

발사 요청이 없는 BUMP에서는 PPO를 호출하지 않는다. 조준 모델의 가정 기반 피해 추정, 쿨다운보다 이른 제안의 추적·재판단, 승인 후 계획 유지는 [v4 동작 설명](<C:/Users/hphci/Desktop/competitive aim-and-shoot/core/docs/PPO-관측-v4.md>)과 같다. 다만 v4의 29항목 입력 표는 위 25항목 표로 대체한다.

관측 버전 5를 사용하며, 이전 관측 모델을 새 입력으로 자동 해석하지 않는다.
