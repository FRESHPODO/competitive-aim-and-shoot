## 판단과 계획 확정

1. 원본의 해당 BUMP 발사 요청이 없거나 승인된 계획이 수행 중이면 PPO를 호출하지 않는다. 학습 샘플과 리플레이 서브 판단도 만들지 않는다.
2. 원본의 지각·예측이 끝난 후 이번 제안의 예정 격발 시각을 구한다. 현재 원본 모델의 `(100 + tc × Th) × 시계 배율` 계산과 반올림·최소 지연 규칙을 사용한다.
3. 예정 시각이 자기 쿨다운 종료보다 앞이면 계획을 확정하지 않는다. 추적을 수행하고 다음 BUMP에서 새로 판단한다. PPO를 호출하지 않고 `쿨다운 중`으로 표시한다. 자동으로 쿨다운 종료 시각에 발사하는 대기열은 만들지 않는다.
4. 실행 가능한 제안은 원본의 운동 계획을 미리 계산하고, 이상적 계획과 지각 결과를 PPO에 제공한다.
5. PPO가 보류하면 미리 계산한 계획은 확정하지 않는다. 운동 노이즈 난수 상태를 복원한 뒤 원래 추적 동작을 계산한다.
6. PPO가 승인하면 계획을 확정한다. 이후 PPO가 다시 취소하지 않으며 예정대로 실제 발사한다. 쿨다운 중이어도 예정 격발이 종료 이후라면 계획을 시작할 수 있다.

## 피해 추정의 의미

현재 BUMP에서 원본이 지각한 타겟 위치·속도를 바탕으로 예정 격발 시점의 위치를 예측한다. 현재 및 새 이상적 운동 계획을 따라 조준이 진행된다고 가정하여 그때의 조준 오차를 구하고, 알려진 외곽·중앙 피해 및 크리티컬 규칙을 적용한다.

이는 **가정한 조준선 기준 추정 피해**이며 보정된 명중 확률이나 확률적 기대 피해가 아니다. 실제 타겟의 미래 위치, 실제 미래 운동 노이즈, 실제 탄 퍼짐 표본을 사용하지 않는다. 탄 퍼짐이나 노이즈에 대한 임의의 추가 확률 공식을 넣지 않는다.

미리 계산한 운동 계획이 보류될 경우, 실제 추적과 난수 소비가 원래 추적 동작과 같음을 검증한다. PPO 판단 자체의 난수 추출은 학습 행동이므로 유지한다.

## 리플레이

- 해당 BUMP에 PPO 판단이 없으면 좌우 에이전트 패널과 중앙 화면의 서브 판단 상자를 숨긴다. 지난 승인을 현재 판단처럼 계속 표시하지 않는다.
- 쿨다운으로 실행할 수 없는 제안은 `쿨다운 중`으로 표시한다.
- 승인되어 실행 중인 계획은 메인 상자에 `발사 계획 수행중`으로 표시한다. 이때 새 PPO 판단은 표시하지 않는다.
- 유효한 요청에 대한 실제 PPO 판단만 `격발 승인` 또는 `보류`로 표시한다.

## 모델·실행 경로

새 관측은 29차원, 버전 4다. 이전 39/45/47차원 모델의 칸을 새 의미로 자동 해석하거나 앞부분을 잘라 쓰지 않는다. 학습 재개·대전·고정 상대 로딩에서 명확한 관측 호환 오류를 표시한다. 보존된 이전 모델 파일은 수정하지 않는다.

공동 학습과 상대 순환 학습, 대전은 같은 요청·계획·쿨다운 처리 경로를 사용한다. 새 버전으로 학습한 모델끼리 이어 학습할 때는 기존 누적 경기 수를 유지한다.

## 검증

`python -m unity_bridge.check_request_policy`

- 요청 없음: PPO 호출·학습 판단·리플레이 상자 없음.
- 상대 노이즈·조준·보상 및 탄 퍼짐 값을 임의로 추가해도 인코딩에 영향 없음.
- 실제 타겟 위치와 미래 실제 운동 궤적을 바꿔도 믿음 기반 추정은 동일함.
- 지각한 위치가 바뀌면 추정이 바뀌며 추정 계산은 난수를 소비하지 않음.
- 미리 계산한 계획을 보류했을 때 원래 추적과 궤적·난수 소비가 동일함.
- 너무 이른 예정 발사는 반복 재판단하며 자동 발사 대기열이 없음.
- 쿨다운 중 시작하되 실제 발사가 이후인 유효한 계획은 승인 가능함.
- 승인 후에는 실제 발사까지 재심사하지 않음.

추가로 새 PPO 공동 학습, 고정 상대 순환 학습, 저장 모델 대전, 새 스키마의 이어 학습, 양쪽 패널 및 중앙 화면의 숨김·쿨다운·수행중 표시를 검증한다.
