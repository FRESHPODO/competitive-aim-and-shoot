# 알파 보상 설정과 PPO 관측 v7

성공 보상과 실패 비용 두 설정을 에이전트별 알파 α 하나로 통합한다. 허용 범위는 0~1이다.

- 내 처치 시 보상: `+2α`
- 상대 처치 시 내 비용: `−2(1−α)`
- 무승부: 0

| α | 성공 보상 | 실패 시 적용값 |
|---:|---:|---:|
| 0 | +0 | −2 |
| 0.25 | +0.5 | −1.5 |
| 0.5 | +1 | −1 |
| 0.75 | +1.5 | −0.5 |
| 1 | +2 | 0 |

이는 승리·패배 확률이 아니라 결과에 적용하는 보상함수 계수다. 두 크기의 합은 항상 2다. 알파가 크다는 이유만으로 실제 승률이 높거나 행동이 항상 공격적이라고 보장하지 않는다.

## 설정 화면

일반 학습기, 상대 목록 순환 학습기, 대전 시뮬레이터에서 A/B 각각 `보상 비율 α`를 설정한다.

- 고정: 알파 값 하나와 실제 성공 보상·실패 비용을 표시한다.
- 범위: 알파 최소·최대·추출 단위를 설정하고, 그 격자에서 실제로 추출 가능한 성공 보상·실패 비용 범위를 표시한다.
- 예를 들어 최소 0, 최대 0.95, 단위 0.3이면 가능한 알파는 0/0.3/0.6/0.9다. 표시 범위도 최대 0.9를 기준으로 성공 +0~+1.8, 실패 −2~−0.2로 계산한다.
- 설정은 기존 자동 저장·불러오기 경로로 유지한다. 계산값은 입력이 바뀔 때 즉시 다시 계산한다.

## 경기별 적용

범위 모드에서는 경기마다 각 에이전트의 알파를 한 번 추출한다. 같은 알파로 성공 보상과 실패 비용을 함께 정한다. 두 계수를 서로 독립적으로 추출하지 않는다.

실제 경기 기록은 `rewardValues`에 알파와 계산된 `win`, `loss`, `draw`를 함께 저장한다. 리플레이에도 알파와 실제 적용 보상값을 표시한다. 상대의 알파는 자기 PPO 입력에 전달하지 않는다.

## 이전 설정 읽기

이전 고정 성공 보상 W와 실패 비용 L은 `α=W/(W+L)`로 읽어온다. 보상 전체 크기는 새 규칙에 따라 2로 정규화된다. W=L=0이면 상대적 선호가 정의되지 않으므로 중립 0.5로 읽는다.

이전 독립 범위는 가능한 비율의 하한·상한을 α 범위로 변환하고 추출 단위를 0.01로 둔다. 이 변환은 이전 독립 추출의 확률분포를 보존하지 않는다. 화면에서 변환된 범위와 적용값을 확인하고 원하는 α 범위·단위로 설정한다.

## PPO 입력

이전의 `own_kill_reward`, `own_loss_cost` 두 입력을 `own_reward_alpha` 하나로 대체한다. 관측은 버전 7, 총 22항목이다. 나머지 입력과 발사 판단·쿨다운 규칙은 [v6](<C:/Users/hphci/Desktop/competitive aim-and-shoot/core/docs/PPO-관측-v6.md>)와 같다. 경기 경과 시간·상태 갱신 후 경과 시간·남은 경기 시간은 추가하지 않는다.

검증 명령: `python -m unity_bridge.check_alpha_rewards`
