# 현재 실행용 core

설계·보상 변경 이력은 [학습기별 변경 아이디어 기록](docs/학습기별-변경-아이디어-기록.md)에 모았습니다.

새 별도 프로그램: 상위 `Start-Generational-Trainer.cmd`. 단일 PPO를 다양한 조준 프리셋으로 학습하며, 설정한 경기 수마다 상대 세대를 자동 갱신합니다. 최근 2~3세대만 유지합니다. [방법·근거·사용법](docs/자동-세대-순환-학습.md)

추가 PPO의 현재 입력: [알파 기반 PPO 관측 v7](docs/PPO-관측-v7.md), 총 22항목. 성공 보상·실패 비용은 알파 하나로 설정하며 화면에 `+2α`, `−2(1−α)` 계산값을 표시합니다. 경기 경과·상태 갱신 후 경과·남은 경기 시간은 입력하지 않습니다. 외곽·중앙 피해, 즉사 여부, 쿨다운 길이는 공통 게임 조건으로 한 번만 입력하며 남은 쿨다운은 두 에이전트 각각의 상태로 입력합니다.

상위 폴더의 실행 CMD 또는 이 폴더의 실행 CMD로 실행합니다. 기존 학습기·대전·병렬 학습 코드를 사용합니다.

| 내부 폴더 | 내용 |
|---|---|
| `unity_bridge`, `src` | 프로그램 및 시뮬레이션 코드 |
| `configs`, `data` | 실행 설정·원본 SAC 모델 |
| `../학습모델` | 학습기 종류별 PPO 모델·복구 체크포인트. 학습기에서 선택한 작업의 모델 경로를 복사할 수 있음 |
| `training-results` | 학습 기록·이어 학습 설정 |
| `match-results` | 대전 결과·리플레이 |
| `local-results` | 화면 설정·로그·개발 검증 결과 |
| `storage-reports` | 과거 경로의 호환 연결 정보 |

대전은 실행 중 모든 경기의 행동 궤적과 메인/서브 판단을 직접 저장합니다. 3D 리플레이를 볼 때 모델을 다시 실행할 필요가 없습니다. 과거에 행동 기록이 빠진 경기만 기존 복원 기능의 대상입니다.

보상 입력 비교는 `python -m unity_bridge.reward_sensitivity --rounds 50`으로 실행합니다. 기존 important model 세 쌍의 가중치를 고정하고 A/B 보상 `(승리, 패배 비용)`을 각각 `(1,1)`, `(5,1)`, `(1,5)`로 교차 비교합니다. 같은 시드와 게임 조건을 사용하며 결과와 모든 리플레이는 `match-results/reward-comparison-*`에 저장됩니다. 승률 차이는 상대 보상 조건별로 해석해야 합니다.

외부 Python·PyTorch를 공유하며, `python-path.txt`에 실행 파일 경로가 있습니다. 현재 PC는 상위 `.venv`를 사용합니다.
폴더를 옮길 때 CMD로 실행하면 저장된 내부 경로를 갱신합니다. 폴더 밖에서 선택한 모델 및 실행 환경은 별도로 유지해야 합니다.

학습기의 병렬 경기 수 0은 CPU·메모리를 기준으로 최대 4개를 자동 선택합니다. 직접 값을 지정할 수도 있습니다.


## 별도 학습기: 고정 A 모델 / B 상대 순환

`Start-Curriculum-Trainer.cmd`로 별도 프로그램을 엽니다. 기존 `Start-Decision-Trainer.cmd`에는 상대 목록 기능을 넣지 않습니다.

1. `A 모델 선택`에서 계속 학습할 PPO ZIP을 선택합니다. 새 무작위 모델을 만들지 않고 이 체크포인트의 가중치로 시작합니다.
2. A의 능력·무기·보상을 설정합니다. A 모델은 상대 목록에 들어가지 않으며 학습 내내 같은 모델이 갱신됩니다.
3. `상대 목록 편집`에서 B 모델과 프로/아마추어 등 프리셋을 순서대로 추가합니다.
4. `선택 A 모델로 새 순환 학습`을 누릅니다. B만 경기마다 교대하고 추가 학습하지 않습니다.

여기서 고정은 A의 학습 대상 모델을 교대하지 않는다는 뜻입니다. A 가중치는 학습으로 갱신되며, B 모델 가중치는 고정됩니다.
상대 순서는 누적 경기 번호 기준이며 병렬 실행과 이어 학습에서도 유지됩니다. 원본 모델 파일은 변경하지 않습니다.

별도 화면 설정은 `local-results/curriculum-trainer-state.json`, 학습 기록은 `curriculum-results`, 체크포인트는 프로젝트 최상위 `학습모델/상대순환`에 저장합니다.
리플레이 생성도 별도 상대 목록을 사용합니다. 학습된 A는 `agent_a.zip`이며 B 참조본과 전체 상대 고정 사본을 함께 보존합니다.

CLI: `python -m unity_bridge.train_curriculum --learner-model ../.important_models/선택모델/agent_a.zip --opponent-pool configs/opponent_pool.example.json --settings configs/competitive_training.json --output curriculum-results/새작업`
